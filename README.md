# Habla+ Espanhol

Crie um aplicativo moderno, profissional e completo para ensino de espanhol chamado Habla+ Espanhol — Seu Professor de Espanhol com IA.

O aplicativo deve funcionar como uma verdadeira plataforma de ensino, permitindo que uma pessoa que nunca estudou espanhol consiga aprender desde o nível iniciante até níveis avançados, com aulas estruturadas, exercícios, conversação e acompanhamento de progresso.

1. OBJETIVO DO APLICATIVO

O objetivo é ensinar espanhol de maneira simples, prática e progressiva, priorizando:

Conversação

Vocabulário

Gramática

Pronúncia

Compreensão auditiva

Leitura

Escrita

Situações reais do cotidiano

Espanhol para viagens

Espanhol profissional

Espanhol para trabalho

Espanhol para provas

Espanhol latino-americano

Espanhol da Espanha

O aplicativo deve adaptar o nível e o ritmo de aprendizagem de cada aluno.

2. TELA INICIAL

Criar uma tela inicial moderna contendo:

Logo do aplicativo

Nome do aluno

Nível atual

Porcentagem de progresso

Sequência de dias estudados

XP acumulado

Pontuação

Próxima aula

Botão "Continuar estudando"

Vocabulário aprendido

Meta diária

Tempo estudado hoje

Desempenho recente

Criar uma interface limpa, moderna e responsiva, funcionando perfeitamente em celulares Android, iPhone, tablets e computadores.

3. CADASTRO E PERFIL

Permitir cadastro utilizando:

Nome

E-mail

Senha

Login com Google

Foto de perfil

Depois do cadastro, realizar um teste de nivelamento.

Perguntar também:

Por que deseja aprender espanhol?

Quanto tempo pode estudar por dia?

Já estudou espanhol?

Deseja espanhol para viagem, trabalho, estudo ou conversação?

Prefere espanhol da Espanha ou espanhol latino-americano?

Com essas informações, criar automaticamente um plano de estudos personalizado.
